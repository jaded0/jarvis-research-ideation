J.A.R.V.I.S. / research ideation / current implementation

How it works.

Overview / Story

You tell Jarvis what you're working on and where you're stuck. Jarvis remembers what you've tried, looks up what scientists have written, and suggests a few new things to try that aren't repeats. You pick which ones you like.

→
→

Jarvis checks both ↓   ·   your choices steer the next round ↺

A brainstorming partner, not an automatic scientist. It suggests experiments; you decide and do the work. Checking a sample can miss a repeat.

↓ starts a session   ↑ conversation
↓ bash: jarvis …   ↑ short markdown / optional JSON
Every CLI invocation is a separate process.
CLI ⇄ persistent state
CLI → search APIs → cached results

The instructions constrain behaviour; bash is not a security sandbox. No Elo ranking, subagents, vector index or web app is implemented here.

papers.py · _s2_throttle

Local shared timestamp, exclusive file lock; S2_MIN_INTERVAL = 1.05 s.

    with open(path, "a+") as f:
        fcntl.flock(f, fcntl.LOCK_EX)  # held until the file closes, so concurrent callers queue up
        f.seek(0)
        last = float(f.read() or 0)
        time.sleep(max(0.0, last + S2_MIN_INTERVAL - time.time()))
        f.seek(0)
        f.truncate()
        f.write(str(time.time()))

ideas.py · fts_query

Plain keywords: quote each word; any word may match.

def fts_query(query: str) -> str:
    """Plain keywords -> an FTS5 query: each word quoted (so '-', ':', quotes, AND etc. are literal), any may match."""
    return " OR ".join('"' + w.replace('"', '""') + '"' for w in query.split())

db.py · SCHEMA / idea_papers

Many-to-many evidence links with a “why this paper” explanation.

CREATE TABLE IF NOT EXISTS idea_papers (
    idea_id  INTEGER NOT NULL REFERENCES ideas(id),
    paper_id TEXT NOT NULL REFERENCES papers(id),
    why      TEXT NOT NULL DEFAULT '',
    PRIMARY KEY (idea_id, paper_id)
);
db.py · SCHEMA / ideas_fts

External-content FTS5 index; insert, delete and update triggers sync it.

CREATE VIRTUAL TABLE IF NOT EXISTS ideas_fts USING fts5(
    title, summary, body, content='ideas', content_rowid='id'
);
CREATE TRIGGER IF NOT EXISTS ideas_ai AFTER INSERT ON ideas BEGIN
    INSERT INTO ideas_fts(rowid, title, summary, body) VALUES (new.id, new.title, new.summary, new.body);
END;
